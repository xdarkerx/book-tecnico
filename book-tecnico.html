Como funciona
SQLite é um arquivo único (data/book-tecnico.sqlite): não precisa instalar nada.
MongoDB é indicado para vários usuários ou servidores. No container, o docker-compose.yml já sobe um MongoDB com usuário e senha definidos no arquivo .env. As variáveis MONGO_URL/MONGO_DB têm prioridade sobre o que for salvo aqui, e BOOK_STORAGE fixa o banco.
⚠️ Excluir um banco
Apaga todo o conteúdo do banco escolhido (books, usuários, lixeira, conexões). Antes, um backup dele é salvo na pasta local de backups. Excluir o banco em uso faz o app recomeçar vazio (com o login ligado, será preciso criar o administrador de novo).
